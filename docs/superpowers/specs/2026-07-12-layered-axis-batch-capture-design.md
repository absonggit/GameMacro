# 分层技能组与单帧检测设计

## 界面

- 技能库保存唯一技能配置和捕获 PNG。
- 爆发循环组保存技能引用，严格按左右顺序执行，只有组内全部 PNG 可用才启动。
- 基础循环组保存技能引用，每次从左向右重新扫描并释放第一个可用技能，不保存循环游标。
- 同一技能可同时拖入两个组；组内 `×` 只移除引用，技能库 `×` 删除技能及所有引用。

## 运行

爆发组检查优先于基础组。爆发开始后锁定组并依次执行；否则基础组每轮从最左侧选择第一个可用技能。发送后的技能必须观察到 PNG 离开可用状态后才能再次触发。

## 性能

每轮计算所有启用技能检测框的最小屏幕包围区域，只执行一次 BitBlt，再从该 BGRA 缓冲区裁剪各技能签名。就绪防抖由三帧降为两帧；按键发送不增加固定延迟。

## 兼容

旧角色勾选字段首次加载时迁移到两个技能组。旧方案没有分组时仍可迁移为基础优先级组。
