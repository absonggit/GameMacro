# 纯视觉与固定一秒公共 CD 设计

## 行为

程序不再计算或展示任何技能本地 CD，不使用基础 CD、施法时间和网络余量。每轮按优先级扫描图标，只把与框选时原始图标连续三帧匹配的技能视为可释放；任何变暗、倒计时、状态切换图标或未知画面都不可释放并直接跳过。

发送按键成功后立即进入固定 1 秒公共锁。锁结束后重新扫描全部技能。状态技能切换到第二图标后不会再次按下，直到自然结束并恢复原始图标。

## 界面与兼容

删除基础 CD、施法时间和网络余量编辑框。悬浮栏与主卡片显示“可用、不可用、未知、已释放”等视觉状态，不显示倒计时。旧 JSON 字段保留以兼容已有方案，但运行时忽略。按键预置新增 `~`，对应 Windows `VK_OEM_3 (0xC0)`，并参与全部热键冲突验证。

## 验证

测试覆盖本地 CD 不影响选择、发送后仅锁一秒、状态图标不可选、`~` 预置与解析。最后执行 Release 测试、构建、发布和启动检查。
