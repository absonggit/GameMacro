# 低占用高准确动态图标识别设计

## 目标

在保持 20ms 扫描响应的前提下，提高动态技能窗口与技能来源栏之间存在缩放、边框、文字和亮度差异时的识别准确度，并避免图标未变化时重复计算全部模板。

## 方案

- 截图范围保持为用户框选的小区域，不做全屏搜索。
- 统一裁掉外围边框与底部按键文字，再缩放为固定网格。
- 特征由整体色相直方图、灰度结构、颜色差和边缘信息组成。整体色相权重最高，避免位置相近但颜色不同的技能被错误匹配。
- 每帧比较全部模板；9 个小型特征的成本远低于截图，避免快速切换期间复用过渡帧结果。
- 动态槽位为空时不发送；非空时按封闭技能集合选择最近模板，避免置信度门限造成漏按。
- 旧方案通过已保存的 PNG 自动重建新特征，不要求重新框选或重新映射。

## 数据流

`小区域截图 -> 归一化 -> 复合特征 -> 空槽检测 -> 最近模板匹配 -> 按键脉冲`

## 约束

- 不使用 OCR、OpenCV、AI 模型或新增第三方依赖。
- 不绕过游戏保护机制。
- 图标变化后的首次扫描必须重新匹配，不能因缓存延迟切换。
- 无可靠匹配时不发送按键。

## 验证

- 单元测试覆盖颜色差异、边缘差异、相同帧缓存、变化后重新匹配和旧 PNG 迁移。
- Release 编译并发布到独立目录，由用户在游戏中验证。
