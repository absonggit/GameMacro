# 主窗口响应式界面优化设计

## 目标

优化非全屏状态下的主窗口可读性和操作效率，并进一步压缩游戏浮窗。

## 主窗口

- 左侧方案名称使用高对比粗体文字；选中项显示蓝色边框和深蓝背景。
- 启动/停止热键不再使用下拉选单，改为点击按钮后直接按下目标键完成绑定，交互与技能映射按键一致。
- 技能映射区域禁止横向滚动，卡片按可用宽度自动换行，只在内容超过高度时显示纵向滚动条。
- 区域标题改为“技能图标与按键映射”，删除“无需排序”。
- “显示游戏浮窗”使用高对比前景色和粗体。
- 删除主窗口的“启动识别”按钮；识别通过全局启停热键或游戏浮窗控制。
- 底部保留状态、浮窗开关、扫描间隔和启停热键绑定。

## 游戏浮窗

- 删除独立的运行状态区域。
- 启停按钮继续用“启动 F5 / 停止 F5”表达当前状态。
- 浮窗宽度缩为 `200px`，高度保持 `40px`。
- 保留拖拽柄、方案选择和启停按钮。

## 单方案导入导出

- 顶部提供“导入”和“导出”按钮。
- 导出当前选中方案为格式化 JSON，包含区域、图标模板、按键映射、热键及浮窗位置。
- 导入 JSON 时始终创建新方案，不覆盖已有方案。
- 导入方案生成新 ID，名称追加“（导入）”，随后写入本地方案目录并自动选中。
- 无效或损坏的 JSON 显示错误，不改变当前方案列表。

## 验证

- 单元测试覆盖通用按键名称转换、`200×40` 浮窗尺寸和方案 JSON 复制导入。
- WPF 编译验证 XAML 事件和控件引用。
- 运行完整测试并重新发布 win-x64 本地版本。
