# 两排拖拽技能与悬浮栏设计

## 范围

在保留现有视觉闭环、施法时间、1秒公共 CD 和固定 CD 逻辑的基础上，增加每技能网络余量、两排拖拽优先级、预制按键、可配置控制热键和游戏置顶悬浮栏。

## 参数与热键

每技能网络余量默认 800ms，范围 100～5000ms，仅用于“施法时间 + 网络余量”的冷却变化确认期限。技能按键、启动切换热键和紧急停止热键只能从 F1～F12、0～9、A～Z 中选择。两个控制热键不得相同，也不得与启用技能按键重复。保存方案时验证并重新注册热键；旧方案默认 F8/F12。

## 队列与优先级

最多 16 个技能，界面固定为两排八列。显示顺序按第一排从左到右，再到第二排。卡片可拖到另一卡片位置执行插入式排序；列表顺序自动写回 Priority 1～N。删除技能名称和优先级编辑框，删除前移/后移按钮。

## 悬浮栏

启动后主窗口最小化，创建无边框、半透明、Topmost、ShowActivated=false 的悬浮栏，显示启用技能图标、按键、倒计时和状态。默认鼠标穿透；按住 Ctrl 时临时允许鼠标操作并可拖动空白区域，松开恢复穿透。停止后关闭悬浮栏并恢复主窗口。位置保存到当前方案。

## 测试

覆盖网络余量验证和确认期限、按键预置集合、热键冲突、列表重排与优先级重编号、悬浮位置持久化。执行完整 Release 测试、构建、发布、无 OCR 检查和 GUI 启动测试。
