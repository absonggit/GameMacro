# 按键助手 v1.0.1 与全局技能库设计

## 目标

将程序显示名称统一为“按键助手”，版本统一为 `1.0.1`，并把每个方案内重复保存的技能图标模板迁移为全局技能库。新建方案时，用户从技能库把图标拖入方案并为该方案绑定按键，无需再次扫描相同技能。

## 品牌与版本

- 主窗口标题显示“按键助手 v1.0.1”。
- Windows 文件属性中的产品名为“按键助手”，产品版本、文件版本和程序集版本均为 `1.0.1` 对应的四段版本。
- 安装程序产品名、开始菜单和桌面快捷方式统一为“按键助手”。快捷方式不附加版本号。
- 安装程序版本为 `1.0.1`，安装包文件名保持 `GameMacro-Setup.exe`，避免破坏现有分发脚本和文档链接。
- 内部程序集名、命名空间、方案保存目录和安装目录继续使用 `GameMacro`，避免升级后丢失配置或造成不必要的大规模重命名。

## 数据模型

### 技能库

全局技能库保存到 `%LOCALAPPDATA%\GameMacro\SkillLibrary.json`，并使用临时文件替换、`.bak` 备份和损坏文件 `.corrupt` 留存。

技能库包含：

- 职业分类：唯一 ID 与用户输入的分类名称。
- 技能模板：唯一 ID、所属职业分类 ID、预览 PNG、视觉签名、像素模板和匹配阈值。
- 默认创建“未分类”，扫描前未选择有效职业时归入该分类。

模板不保存技能名称和按键。不同外观即为不同模板，即使它们代表同一个实际技能。

### 方案映射

方案中的技能映射只保存：

- 映射唯一 ID。
- 技能模板 ID。
- 当前方案的按键。
- 启用状态。

同一个技能模板可以被多个方案引用并绑定不同按键。一个方案内同一模板 ID 只引用一次；同一实际技能的多个不同外观模板可以同时加入，并绑定相同按键。识别到其中任意模板时发送其方案映射按键。

## 界面与交互

### 主窗口

- 保留每个方案独立的动态监控区域设置。
- 原批量扫描技能来源和框选单个技能入口移入技能库侧栏。
- 方案映射区只显示当前方案已选模板、按键按钮、启用状态和移除按钮。
- 方案映射区继续按窗口宽度自动换行，不增加技能名称或顺序语义。

### 技能库侧栏

主窗口右侧增加可展开、可收起的技能库侧栏：

- 侧栏顶部提供职业分类选择与新建、重命名、删除空分类操作。
- 技能图标按可用宽度自适应排列。
- 用户可把图标拖入方案映射区；双击图标也可添加，作为拖拽的备用操作。
- 已在当前方案引用的同一模板显示已添加状态；再次拖入不会产生完全相同的引用，而是高亮方案中的现有映射。
- 不同模板即使绑定相同按键也可分别加入。
- 批量扫描与框选单个技能均添加到当前职业分类。
- 从方案移除只删除引用，不删除全局模板。

### 删除保护

- 删除空职业分类时，其中没有模板才允许删除。
- 删除技能模板前检查所有方案引用。
- 存在引用时拒绝删除，并列出引用该模板的方案名称。
- 用户先从相应方案移除后才能删除模板。

## 运行时数据流

1. 选择方案后，根据方案映射中的模板 ID 从技能库解析完整识别模板。
2. 启动前校验所有引用均可解析且所有启用映射均已绑定受支持按键。
3. 缺失模板时在映射卡片显示“模板缺失”，阻止启动并报告缺失数量。
4. 动态区域截图只与当前方案解析出的模板比较。
5. 匹配成功后发送当前方案映射中保存的按键。

## 旧方案迁移

- 技能库不存在或方案仍包含旧版内嵌模板时启动迁移。
- 迁移前保留原方案 JSON 的备份。
- 使用现有视觉特征距离规则对模板去重；相同模板复用技能库 ID。
- 无法确定职业的旧模板归入“未分类”。
- 将旧映射替换为模板 ID 引用，同时保留原按键、启用状态与映射 ID。
- 迁移应可重复执行；中途失败后再次启动不会产生重复模板或破坏原方案。

## 导入与导出

- 单个方案导出包包含方案数据以及该方案实际引用的技能模板和相关职业分类。
- 导入时先合并职业与模板，再建立方案引用。
- 同 ID 且内容相同的模板直接复用。
- 同 ID 但内容不同的模板生成新 ID，并同步重写导入方案中的引用，绝不覆盖本机模板。
- 按视觉特征确认重复的模板复用本机已有模板，避免多次导入产生副本。

## 错误恢复

- 技能库保存采用临时文件写入后原子替换，并保留最近一次备份。
- 主文件 JSON 损坏时复制为 `.corrupt`，再尝试读取 `.bak`。
- 备份也不可用时不自动覆盖原文件，向用户提示技能库无法读取。
- 拖放重复模板不报错，只定位并高亮已存在映射。
- 扫描结果为空时不修改技能库。

## 测试范围

- 品牌名、程序集版本、安装器版本和快捷方式名称一致性。
- 技能库保存、加载、备份恢复与损坏文件处理。
- 职业分类新建、重命名、删除限制。
- 模板去重和不同外观模板共存。
- 方案引用添加、重复拖放、同按键多模板和移除行为。
- 被引用模板删除保护。
- 旧方案迁移的幂等性、按键保留与备份行为。
- 方案导入导出携带模板、合并去重和 ID 冲突改写。
- 运行前缺失模板校验与运行时引用解析。
- WPF 拖放数据类型与添加逻辑使用可单测的纯服务实现，界面仅负责事件转发。

## 不在本次范围

- 不给技能模板添加名称。
- 不按技能优先级排序。
- 不将内部程序集、命名空间、安装路径或 `%LOCALAPPDATA%\GameMacro` 配置目录改名。
- 不引入数据库。
