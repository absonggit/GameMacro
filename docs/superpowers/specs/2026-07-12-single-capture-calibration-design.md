# 单次框选自动标定设计

## 目标

将视觉标定简化为一次操作：用户在技能就绪时框选图标，程序自动保存技能 PNG、建立就绪基准并估算画面抖动，不再要求记录冷却状态。

## 标定流程

框选窗口关闭后，主窗口保持隐藏，程序以约 50ms 间隔捕获五帧。第一帧保存为就绪 PNG并作为技能卡片图标；五帧特征取逐项平均作为就绪基准；各帧到基准的最大距离用于计算就绪容差。标定成功后状态显示“已捕获”。捕获失败则不覆盖原标定。

## 单基准状态判定

当前特征到就绪基准的距离不高于就绪阈值时判定就绪；高于变化阈值时判定冷却；两个阈值之间为未知。就绪阈值取自动测得抖动的安全倍数并设最小值，变化阈值必须显著高于就绪阈值形成迟滞区。仍使用连续三帧就绪触发按键、连续两帧变化确认释放。

## 数据兼容

保留旧字段以兼容已有方案，但新逻辑只需要检测区域、就绪基准、自动容差和就绪 PNG。旧方案若没有自动容差，必须重新框选后才能启动，防止混用旧的双参考标定。

## 界面

删除“记录就绪”“记录冷却”、双预览区及右侧固定 CD 说明。只保留“框选并捕获技能”按钮和“未捕获/已捕获”状态。技能卡片继续固定显示捕获的就绪 PNG。

## 验证

测试覆盖多帧平均、容差计算、单基准就绪/变化/未知分类、标定完整性以及闭环状态机兼容。最后执行完整 Release 测试、构建、发布和 GUI 启动检查。
