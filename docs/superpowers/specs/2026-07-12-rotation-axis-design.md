# 循环轴调度设计

## 行为

- 爆发轴按技能卡片顺序执行，只有轴内全部技能 PNG 可用时才启动。
- 爆发轴开始后锁定当前轴，逐个等待对应技能可用并发送，直到整轴结束。
- 非爆发期间，短 CD 插入技能可用时优先发送；否则按顺序循环填充轴。
- 任何技能发送后，在观察到其 PNG 离开可用状态前不会重复发送。
- PNG 连续三帧确认继续作为最终发送防抖。

## 配置

每个技能提供“爆发轴”“填充轴”“短 CD 插入”三个角色开关。卡片从左到右、从上到下的顺序同时决定爆发轴和填充轴内部顺序。F3 可以同时勾选爆发轴和短 CD 插入。

## 界面清理

- 删除紧急停止热键设置、全局热键注册和按钮。
- 技能图标不覆盖显示运行状态文字。
- 保留启动/停止按钮和可配置启动热键。

## 兼容性

旧 JSON 中的紧急热键字段可继续读取但不再使用。未配置任何轴角色的旧方案继续使用原有视觉优先级扫描。
