# 纯视觉释放与技能槽拖拽设计

## 目标

- 自动释放完全依据已捕获 PNG 的连续就绪判断，不设置公共 CD 或其他时间锁。
- 最多 16 个技能始终以两排、每排 8 个显示，操作按钮不得遮挡技能块。
- 技能块右上角提供 `×` 删除按钮；拖动时原块淡化、目标块高亮，松开后按位置更新优先级。

## 设计

视觉调度路径忽略全局锁，按键发送后立即回到下一次图像扫描。现有连续三帧就绪确认继续承担防抖职责。

技能列表占满主内容宽度，`＋技能` 放在区域顶部，删除入口放进卡片。拖拽使用 WPF 容器的透明度、边框与鼠标光标反馈，不引入外部控件库。

## 验证

- 单元测试证明发送按键后同一时刻仍可选择视觉就绪技能。
- RuleOrder 现有测试继续证明拖拽后优先级重排。
- 完整构建、测试、发布及启动冒烟验证。
