# 标定预览与紧凑技能卡片设计

## 目标

让用户能直观看出“记录就绪”和“记录冷却”实际捕获了什么，并缩小技能队列卡片，提高横向可见技能数量。

## 数据

每个技能在现有视觉特征之外保存两张 PNG Base64 字符串：就绪预览和冷却预览。预览随方案 JSON 保存，不创建外部图片文件。重新框选区域时同时清空两张预览和两组检测特征，避免区域与样本不一致。

## 捕获与显示

记录状态时，同一帧同时生成检测特征和 PNG 预览，保证显示内容就是参与标定的画面。标定区以 80×80 方框并排显示就绪与冷却预览；未记录时显示文字占位。就绪使用绿色标识，冷却使用蓝色标识。

## 技能卡片

技能卡片缩小为约 92×128。卡片顶部固定显示 56×56 的就绪预览，替代技能名称；按键显示在下方，倒计时覆盖在图标右下角，启用开关位于底部。未记录就绪图时显示简洁占位图形。运行时不在两张预览之间切换。

## 测试与兼容

旧方案缺少预览字段时仍能加载并显示占位。测试覆盖预览字段 JSON 往返、PNG 编解码和重新框选清空规则。最后运行完整 Release 测试、构建、发布和启动冒烟测试。
