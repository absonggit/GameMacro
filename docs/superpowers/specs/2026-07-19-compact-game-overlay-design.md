# 紧凑游戏浮窗设计

## 目标

将现有 `390×72` 游戏浮窗缩小为约 `250×40`，减少对游戏画面的遮挡，同时保留方案切换、运行状态和启停控制。

## 布局

- 浮窗固定尺寸：`250×40`。
- 左侧提供 `18px` 独立拖拽柄。
- 方案选择框固定为 `96px`，单行省略过长方案名。
- 状态区域宽约 `56px`，显示“运行”或“停止”。
- 启停按钮宽约 `74px`，显示操作和当前热键，例如“启动 F5”或“停止 F5”。
- 外边距、内边距、圆角和字体同步缩小。

## 行为

- 保持现有前台显示、拖动、方案切换锁定及焦点返回游戏逻辑不变。
- 方案运行时禁止切换。
- 启动热键修改或方案切换后，按钮文字立即使用当前方案热键。

## 验证

- 单元测试覆盖紧凑尺寸常量和启停按钮文字。
- 运行完整解决方案测试并生成 win-x64 发布目录。
