# 按键助手 v1.0.4

这是一个 Windows WPF 图标识别宏。程序持续扫描游戏中的一个动态技能图标区域，识别到已绑定图标后持续发送对应按键；图标变化时，在下一次扫描立即切换按键。

程序只使用屏幕截图和 Windows 普通 `SendInput`，不读取游戏内存、不注入游戏进程、不使用 OCR，也不提供反作弊绕过。

## 使用方法

1. 启动游戏，并保持窗口模式或无边框窗口模式。
2. 打开程序，在顶部选择目标游戏窗口。
3. 点击“框选动态区域”，只框住游戏里会动态变化的单个技能图标窗口。
4. 在右侧常驻技能库选择职业分类；可新建、重命名或删除空分类，默认提供“未分类”。
5. 在技能库中点击“扫描技能来源”，框住游戏“战斗辅助技能组”弹窗里的图标网格；也可以用“框选单个技能”补充模板。
6. 程序会自动分离图标、忽略空槽并复用重复模板。把技能图标拖到左侧方案映射区，双击图标也可添加。
7. 点击方案映射卡片上的按键按钮，然后直接按下该方案使用的技能键。不同图标模板可以绑定同一个按键。
8. 完成绑定后点击“保存全部映射”。以后新建方案可直接复用技能库，无需重复扫描。
9. 点击底部启停热键按钮后直接按下新的热键，保存方案，再回到游戏通过热键或浮窗启动识别。

勾选“显示游戏浮窗”后，目标游戏位于前台时会显示紧凑控制条。浮窗通过“启动 F5 / 停止 F5”按钮表示状态并控制识别；只有停止状态下才能切换同一游戏进程的其他方案，切换后不会自动启动。停止状态下可拖动浮窗，位置会按游戏客户区的相对坐标保存，游戏窗口移动后仍会跟随。

## 方案导入导出

- 点击顶部“导出”，可把当前方案保存为独立 `.json` 文件。
- 点击顶部“导入”选择方案文件；程序会生成新 ID 和“（导入）”名称，不覆盖已有方案。
- 导出文件会携带当前方案引用的技能模板与职业分类。导入时会自动合并到本机技能库，并处理重复模板与 ID 冲突。
- 程序日常保存的方案位于 `%LOCALAPPDATA%\GameMacro\Profiles`。
- 全局技能库位于 `%LOCALAPPDATA%\GameMacro\SkillLibrary.json`，同时保留最近一次 `.bak` 备份；各方案只保存模板引用和自己的按键映射。

识别到图标时，程序每个扫描周期都会发送一次绑定按键。同一图标持续显示就持续按同一个键；变成另一个已绑定图标后，下一次扫描立即改按新按键。像素距离超出门槛或前两名过于接近时视为未知图标，不会发送按键。

## 技能库与手动优先按键

- 批量扫描遗漏某个图标时，可在技能库中点击“框选单个技能”，只框住该技能的完整图标。
- 同一个模板在一个方案内只能添加一次，但同一技能的不同状态图标可以分别保存为模板，并绑定相同按键。
- 被任一方案引用的模板不能从技能库删除；先从相关方案移除并保存后才能删除。
- 首次运行 v1.0.1 或更高版本时，旧方案内嵌的图标会自动迁移到“未分类”并按视觉特征去重；方案按键保持不变。
- 在窗口底部点击“添加打断键”后直接按下目标键，可为每个方案配置多个优先打断键，并可通过标签上的 `×` 单独删除。
- 自动识别运行时，真实按下任一优先打断键会立即暂停自动截图和按键发送；多个键同时按住时持续暂停，最后一个键松开后等待 1 秒自动恢复。
- 优先打断键可以与技能映射键相同，但不能与启动/停止热键相同。程序自身通过 `SendInput` 发送的按键不会触发暂停。
- 单图标模板和优先打断键均随方案保存，并包含在单个方案的导入导出 JSON 中。

## 运行设置

- 扫描间隔默认 `20ms`，可设置为 `10–500ms`。
- 启动/停止热键支持 `F1–F12`、`0–9`、`A–Z` 和 `~`。
- 启动热键和启用中的技能映射按键不能重复。
- 只有目标游戏窗口位于前台时才会发送按键。
- 浮窗只在目标游戏前台显示；点击浮窗启停后会自动把输入焦点还给游戏。
- 每个方案最多保存 32 个图标映射。
- 主窗口的技能卡片会随窗口宽度自动换行，不再使用横向滚动条。
- 技能库图标从左到右紧密换行，不会再把少量技能平均撑满整个高度；删除按钮只在当前悬停的图标上显示。
- 主窗口保留 Windows 原生拖动、缩放和窗口按钮，同时使用与应用内容一致的深色标题栏。

## 版本更新

- 从 v1.0.2 开始，程序启动后会静默检查 GitHub 最新正式版；发现更高版本时提示前往下载，断网或 GitHub 不可用不会影响主程序。
- 下载新版 `GameMacro-Setup.exe` 后直接运行即可覆盖升级，方案和技能库保存在 `%LOCALAPPDATA%\GameMacro`，不会随升级删除。
- 已安装的 v1.0.1 没有更新检查代码，需要手动安装一次 v1.0.2 或更高版本；从 v1.0.2 起会自动提示最新正式版。

## 图标扫描建议

- 框选区域应尽量只包含动态技能图标，不要包含旁边按钮或大面积背景。
- 技能来源区域不要求固定行列、图标数量、尺寸或间距，但每个图标应完整显示并具有清晰边界。
- 空槽会根据低纹理特征自动过滤；如果背景元素被误识别，可在扫描结果中删除对应卡片。
- 技能来源图片会保存为固定尺寸的完整彩色像素模板。运行时允许小范围位置偏移，并综合比较中心图案、颜色和边缘；F2 与 1 这类同色技能主要依靠中心图案区分。
- 旧版循环方案会保留在本地，但需要重新框选动态区域并录入图标映射。

## 构建与发布

```powershell
dotnet test GameMacro.sln
powershell -ExecutionPolicy Bypass -File scripts/publish.ps1
```

发布结果位于：

```text
artifacts\win-x64-auto\GameMacro.App.exe
```

## 构建 Windows 安装程序

先安装 [Inno Setup 6](https://jrsoftware.org/isdl.php)，然后执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-installer.ps1
```

指定版本号：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-installer.ps1 -Version 1.0.4
```

最终安装包位于：

```text
artifacts\installer\GameMacro-Setup.exe
```

安装程序按当前用户安装到 `%LOCALAPPDATA%\Programs\GameMacro`，无需管理员权限，并创建开始菜单入口和可选桌面快捷方式。升级或卸载程序不会删除 `%LOCALAPPDATA%\GameMacro\Profiles` 中的用户方案。分发给朋友时只需要发送 `GameMacro-Setup.exe`；需要共享方案时，再单独导出对应 JSON 文件。
